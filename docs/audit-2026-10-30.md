# Auditoría técnica de IDEATHON

Fecha: 2026-10-30 · Rama revisada: `main`

## Alcance y resultados

- **Rutas SPA:** Vercel sirve `dist` y reescribe las rutas de cliente a `index.html`, lo que habilita accesos directos a páginas de React Router.
- **Videos de producción:** los MP4 permanecen ignorados por Git. El build de Vercel los descarga desde el Blob público a `public/media/videos/` y el validador comprueba los ocho videos y sus pósteres dentro de `dist`.
- **Accesibilidad visual P1:** se ajustaron los colores de texto sobre los acentos naranja, verde y azul, y se corrigió el nivel del encabezado de los pasos metodológicos. El detector visual ya no reporta problemas de contraste ni saltos de encabezados en Inicio, Videos y Metodología.
- **Diseño:** se conservaron la composición, paleta, componentes y animaciones existentes.
- **Git:** `public/media/videos/`, `BORRAR/` y `dist/` están fuera de los cambios versionados.

## Hallazgos menores

- Algunas etiquetas informativas usan tipografía compacta de 10 px y la interfaz reutiliza tarjetas anidadas e iconos dentro de bloques. Son decisiones preexistentes del sistema visual; no impiden publicar y se conservaron para respetar el diseño aprobado.

## Verificación local

- `npm run verify`: formato, TypeScript, ESLint, 5 pruebas y build completados correctamente.
- `npm run test:media`: reproducción local, carga diferida, copia del organizador, secuencia metodológica y anchos responsive completados correctamente.
- `npm run build:vercel`: probado con un servidor HTTP local como origen Blob; sincronizó los ocho MP4 y validó su presencia en `dist/media/videos/`.
- El build directo también encontró los ocho MP4 y sus pósteres en `dist`.

Se usó `npm` porque Bun no está instalado en este entorno.

## Pendiente externo de publicación

No se pudo cargar el almacén ni verificar un despliegue real: Vercel CLI no tiene sesión iniciada, el proyecto no está vinculado localmente y este entorno no dispone de `MEDIA_BLOB_BASE_URL` ni `BLOB_READ_WRITE_TOKEN`. Antes del despliegue de producción se necesita iniciar sesión y vincular el proyecto con Vercel, cargar los medios con `npm run media:upload`, y configurar `MEDIA_BLOB_BASE_URL` en los entornos de build de Vercel. El token de escritura solo se necesita para la carga y no forma parte del frontend.
